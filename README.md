# เว็บไซต์บริษัทโซลาร์เซลล์

เว็บไซต์แบบคงที่ (static site) สำหรับธุรกิจติดตั้งโซลาร์เซลล์
สร้างด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องมีเครื่องมือ build ใด ๆ

## โครงสร้างโปรเจคต์

```
.
├── index.html               หน้าเว็บทั้งหมด (โครงสร้าง HTML แบบ semantic)
├── assets/
│   ├── site.webmanifest       ข้อมูลเว็บไซต์เมื่อติดตั้งเป็น App (PWA)
│   ├── css/
│   │   └── styles.css       สไตล์ทั้งหมด (เรียงลำดับ: tokens → base → components → responsive)
│   ├── js/
│   │   └── main.js          ฟีเจอร์ทั้งหมด (ธีม เมนู reveal เครื่องคิดเลข)
│   └── img/                 รูปภาพ / วิดีโอ / โลโก้ / favicon (PNG + SVG + MP4)
├── backup/                  ไฟล์ต้นแบบเดิม (เก็บไว้เปรียบเทียบ ลบได้ถ้าไม่ต้องการ)
└── README.md
```

## เริ่มใช้งาน

ดับเบิลคลิก `index.html` เพื่อเปิดดูในเบราว์เซอร์ได้ทันที
(ไม่ต้องรันเซิร์ฟเวอร์ ไม่ต้องใช้ `npm install`)

## สิ่งที่ต้องแก้ก่อนเผยแพร่

| ตำแหน่ง | สิ่งที่ต้องเปลี่ยน |
| --- | --- |
| `index.html` | ค้นหา `ชื่อบริษัทคุณ` แล้วแทนด้วยชื่อจริง |
| `index.html` | ค้นหา `info@yourcompany.com` แล้วแทนด้วยอีเมลจริง |
| `index.html` | ค้นหา `0XX-XXX-XXXX` แล้วแทนด้วยเบอร์จริง (ทั้งใน `href="tel:..."`) |
| `index.html` | ค้นหา `@yourcompany` แล้วแทนด้วย LINE ID จริง |
| `index.html` | ค้นหา `data-count` ในส่วนสถิติ แล้วแทนด้วยตัวเลขจริง |
| `assets/site.webmanifest` | เปลี่ยน `name` / `short_name` / `description` เป็นของจริง |
| `assets/js/main.js` | แก้ค่า `CONFIG.calculator` ให้ตรงกับราคาจริงของบริษัท |
| `assets/img/` | เปลี่ยนไฟล์ `placeholder-*.svg` เป็นรูปจริง (แนะนำ `.webp` ขนาด 800×450 และ 1200×900) |

## วิดีโอส่วนหัว (Hero)

วิดีโออยู่ที่ `assets/img/hero.mp4` และตั้งค่าไว้ให้เล่นวนอัตโนมัติแบบไม่มีเสียง (`muted`, `loop`, `playsinline`) ซึ่งจำเป็นต่อการเล่นอัตโนมัติบนมือถือ

**วิธีเปลี่ยนวิดีโอ:** เปลี่ยนไฟล์ใหม่มาแล้วเขียนทับชื่อ `assets/img/hero.mp4` ทันที ไม่ต้องแก้โค้ดใด ๆ

- รูปแทนที่ขณะโหลดคือ `assets/img/placeholder-hero.svg` (ดูค่า `poster` ใน `index.html`)
- ถ้าผู้ใช้เปิด `prefers-reduced-motion` วิดีโอจะหยุดเล่นและแสดงรูปแทนที่แทน
- วิดีโอจะหยุดเล่นอัตโนมัติเมื่อเลื่อนออกจากหน้าจอ เพื่อประหยัดแบตเตอรี่และ CPU
- ควรลดขนาดไฟล์ให้ต่ำกว่า 3–5 MB และใช้ H.264 (`.mp4`)
  `ffmpeg -i input.mp4 -vf "scale=1600:-2" -crf 30 -an -movflags +faststart hero.mp4`
- ถ้าขนาดไม่พอดีกับจอ ไม่ต้องแก้ CSS เพราะ `.hero__media` ตั้ง `object-fit: cover` ไว้แล้ว

## ปรับแต่งหน้าตา

สีและระยะห่างทั้งหมดอยู่ที่บล็อก `:root` ด้านบนสุดของ `assets/css/styles.css`

```css
:root {
  --color-primary: ...   /* สีหลัก */
  --color-accent:  ...   /* สีเสริม (เหลือง) */
  --container: ...       /* ความกว้างสูงสุดของเนื้อหา */
}
```

รองรับโหมดมืด 2 แบบ

- อัตโนมัติตามการตั้งค่าระบบปฏิบัติการ (ค่าเริ่มต้น)
- ผู้ใช้กดสลับเองผ่านปุ่มดวงอาทิตย์/ดวงจันทร์ แล้วจะถูกจดจำไว้ใน `localStorage`

## เพิ่มส่วนใหม่

1. คัดลอกโครงสร้าง `<section>` ที่มีอยู่ใน `index.html`
2. ใส่ `id` และเพิ่มลิงก์ในเมนูด้านบน
3. เพิ่ม `data-reveal` เพื่อให้มีเอฟเฟกต์เลื่อนขึ้น (ถ้ามีหลายชิ้นให้ครอบด้วย `data-reveal-group` เพื่อให้แสดงทีละชิ้น)
4. สไตล์ที่เกี่ยวข้องอยู่ใน `assets/css/styles.css` ช่วง `Components`

## ตรวจสอบก่อนขึ้นเว็บจริง

- ทดสอบบน Chrome / Edge / Safari / Firefox รุ่นล่าสุด
- ทดสอบที่ความกว้าง 360px, 768px, 1440px
- ตรวจสอบความคมชัดของคีย์บอร์ด (Tab) และคอนทราสต์ของข้อความ
- ตรวจสอบด้วย [PageSpeed Insights](https://pagespeed.web.dev/)
- ตรวจสอบรูปภาพและ alt text ด้วย Lighthouse

## ข้อควรรู้

- โฟนต์มาจาก Google Fonts ต้องต่ออินเทอร์เน็ต ถ้าต้องการใช้งานออฟไลน์ให้ดาวน์โหลดฟอนต์มาไว้ใน `assets/fonts/`
- เว็บไซต์เป็นแบบ static จึงวางได้ที่ GitHub Pages, Netlify, Vercel หรือโฮสติ้งปกติ
